# Основи роботи з Git та системами контролю версій

## Що таке системи контролю версій (VCS) та Git?
**Система контролю версій (VCS)** — це програмне забезпечення, яке реєструє зміни у файлах з часом, дозволяючи вам повернутися до певних версій пізніше, порівнювати зміни та ефективно працювати в команді. 

**Git** — це найпопулярніша у світі розподілена система контролю версій, створена Лінусом Торвальдсом у 2005 році. На відміну від централізованих систем, у Git кожен розробник має повну локальну копію всієї історії проекту.

## Основні можливості та переваги Git
* **Розподіленість:** Кожен розробник має повну копію репозиторію, що дозволяє працювати офлайн.
* **Швидкість:** Більшість операцій виконуються локально, що робить Git надзвичайно швидким.
* **Потужне галуження (branching):** Створення нових гілок для експериментів або розробки нових функцій є швидким і безпечним процесом.
* **Безпека та цілісність:** Вся інформація хешується (SHA-1), тому неможливо змінити файл або історію без відома Git.

## 10 базових команд Git

1. `git init` — створює новий локальний репозиторій у поточній папці.
2. `git clone <url>` — копіює існуючий віддалений репозиторій на ваш комп'ютер.
3. `git status` — показує стан файлів у робочій директорії (змінені, додані, невідстежувані).
4. `git add <файл>` — додає зміни у файлі до індексу (staging area) для підготовки до коміту.
5. `git commit -m "Повідомлення"` — фіксує проіндексовані зміни та зберігає їх в історії локального репозиторію.
6. `git push` — відправляє ваші локальні коміти до віддаленого репозиторію (наприклад, на GitHub).
7. `git pull` — завантажує останні зміни з віддаленого репозиторію та об'єднує їх з вашою поточною гілкою.
8. `git branch` — показує список усіх локальних гілок.
9. `git checkout <назва_гілки>` — перемикає вас на вказану гілку (у нових версіях Git також використовують `git switch`).
10. `git merge <назва_гілки>` — зливає вказану гілку з тією, на якій ви зараз знаходитесь.
